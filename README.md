## ✨ Features
- **Product Catalog:** Browse groceries by categories (e.g., Fresh Produce, Dairy, Bakery, Beverages).
- **Interactive Shopping Cart:** Add items to the cart, adjust quantities, or remove products in real time.
- **Automatic Price Calculation:** Dynamically updates item subtotals and total checkout cost.
- **Responsive Design:** Optimized for smooth browsing on mobile phones, tablets, and desktops.

## 🛠️ Technologies Used
- **HTML5** – Page structure and semantic layout
- **CSS3** – Styling, Flexbox/Grid layouts, and responsive design
- **JavaScript** – Shopping cart logic, DOM manipulation, and dynamic totals
